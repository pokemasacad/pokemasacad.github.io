03 / 수업 기록

선택 기록

보상 추가·수정·삭제는 현재 보유량에 반영됩니다.

기록된 보상

아직 기록된 선택이 없습니다.

시작 전 목표 점검

목표량·배수와 선택 조건으로 완성 가능 여부를 확인합니다. 쿠쿠이·클라벨 각 1회 필수, 시작 보유 0, 시험 보상 포함. 필요한 등장·색이 맞는 조건으로 계산합니다.

허용은 사용 가능한 후보, 필수는 해당 항목을 최소 1회 선택하는 조건입니다.

연계 전투

연계는 트레이너별 1계열 · 민진·네모·단델·로켓단 최대 3회, 샤틀레느 최대 4회. 필수는 1단계 이상 선택입니다.

결과 읽는 법

여유 칸은 표시된 보상을 확보했을 때 목표 수급에 쓰지 않아도 되는 선택 수입니다. 필요한 선택지의 등장과 색, 연계 순서가 맞아야 하며 여유 칸의 선택이 필수 보상을 차단하면 안 됩니다.

최저·중간·최대는 실제 가능한 보상 수량으로 비교합니다. 교류는 150/300/400, 질문은 150/300/600, 30·450 도박과 오박사는 중간에서도 낮은 수량을 사용합니다. 웅은 30/210/450입니다. 쿠쿠이는 지정한 색을 1턴에 받고, 볼가이는 필요한 색을 받는 조건입니다. 자동은 빨강·파랑 중 목표 필요량이 큰 색이며 동률이면 빨강입니다. 각 기준은 실제 성공 확률을 뜻하지 않습니다.

등장 턴·연계·선택 잠금을 적용합니다. 반복 미확인 선택지는 1회, 교류는 묶음별 1회, 질문은 질문별 1회로 계산합니다. 불가능과 최소 횟수는 해당 조건의 탐색이 끝난 뒤 표시합니다.

04 / 이번 턴의 선택

이번 턴 추천 선택지 BETA

현재 부족량 + 남은 턴 + 선택 기록

이번 턴의 선택지 후보들 중 선택 시 이후 턴들 진행이 얼마나 유리해지는지 비교해 10개의 추천 선택지를 제공합니다.

다른 선택지 검색

추천 10개 중 등장 항목이 없다면 실제로 보이는 선택지를 골라 순위와 이유를 확인하세요. 기록과 보유량에는 반영하지 않습니다.

추천 계산 후 선택지를 고를 수 있습니다.

참고용

입력값·계산 규칙·가정에 따른 추천입니다. 등장·보상·최적 선택·목표 달성을 보장하지 않습니다. 게임 화면과 목표·보유량을 확인해 직접 판단하세요.

추천 순위

큰 보상과 이후 네 색의 부족량을 함께 비교합니다. 전투 배율·확정 수급·낮은 확률과 색 랜덤의 낭비도 반영하며, 목표 달성 가능성이 더 높다는 뜻은 아닙니다.

클라벨 색 추천

현재 턴과 부족량에 따라 추천 색을 안내합니다.

분석 전제와 제외된 보상

기록 누락·중간 삭제가 있으면 실제 다음 턴을 지정하세요. 수동으로 지정한 턴은 선택 기록을 추가해도 유지됩니다.

  • 선택 추가 목록 전체를 현재 턴과 기록으로 걸러 추천합니다. 별도 범위가 없으면 1~11턴이며 시험 6·12턴은 일반 선택에서 제외합니다. 직접 입력한 항목은 범위가 없어 추천 후보로 만들지 않습니다.
  • 현재 보상과 남은 턴의 수급 가능성을 함께 평가합니다. 미래 등장 여부가 미정이므로 현재 정보 기준의 BETA 추천입니다.
  • 오박사는 네 색 30개씩 95%, 400개씩 5%입니다. 30개와 400개 결과를 따로 평가하고, 선택 후 그린이 사라지는 것도 반영합니다. 막판에 400개 결과만 완성을 만들 수 있다면 그 조건을 표시합니다.
  • 클라벨은 실제로 보이는 색별 선택지로 추천합니다. 한 색 기본 90개에 전투 배수를 적용하며 네 색 동시 보상이 아닙니다. 11턴 전이라도 추천 색이 뜨면 선택할 수 있습니다. 선택 기록이 있으면 제외하며, 보이지 않은 미래의 원하는 색을 확정 보상으로 예약하지 않습니다.
  • 그린→오박사는 허용하고 오박사→그린은 차단합니다. 쿠쿠이·클라벨·그린은 한 번만 사용합니다. 반복 미확인 항목도 각 1회, 쉬는시간은 묶음별 1회, N·플라타느는 답변을 합쳐 각각 1회라는 보수적인 전제를 둡니다.
  • 민진·네모·단델·로켓단·샤틀레느만 선행 단계를 적용합니다. 채두·운향 번호는 독립적인 보상 종류입니다. 배수는 전투에만 적용하고 시험 정산은 중복하지 않습니다.
  • 사용자 지정 균등 모델로 교류 수량은 각 1/3, 30/450은 각 1/2, 질문 수량은 각 1/4, 볼가이·쿠쿠이 색은 각 1/4로 계산합니다. 웅은 3색 각 1/3과 8수량 각 1/8의 독립을 가정합니다. 사용자가 고르는 교류 트레이너·질문 답변은 색 랜덤으로 계산하지 않습니다.
  • 사용자 확인 규칙: 클라벨을 아직 고르지 않았다면 11턴은 반드시 클라벨에 사용합니다. 자유 선택 마감은 10턴이며, 일찍 클라벨을 골랐다면 11턴까지 자유롭게 선택할 수 있습니다.
  • 추천은 미래 선택지가 등장할 수 있다는 모델을 사용합니다. 서로 다른 보상 판정의 독립을 가정하며, 정확한 완주 성공률을 표시하지 않습니다. 목표는 네 색 오브이며 기술머신 등 별도 재화는 포함하지 않습니다.

확률표 안내

아래 확률은 첫 플레이 기준이며, 해당 에리어가 등장했을 때 그 안에서 각 선택지가 등장할 확률입니다. 에리어 자체의 출현 확률과는 별도입니다.

오박사 보상 결과 (오박사를 선택한 경우): 네 색 모두 30개씩 95%, 400개씩 5%입니다. 오박사 등장 확률과는 별개의 보상 판정 확률이며, absolutelypm의 내부 드롭 데이터 분석을 근거로 표시합니다.

그린과 오박사 등장 확률: 데이터마이닝 자료에는 도전 1회 완주당 +1.18~2.35%p 확률이 증가한다고 표시되어 있습니다. 증가량은 일정하지 않고, 도전 횟수가 늘어날수록 작아집니다. 4월 이벤트 공지에서 출현율 상승에 상한이 있다고 밝혔지만, 상한 확률과 최대 확률에 도달하는 데 필요한 도전 횟수는 공개되지 않았습니다.

해외 유저들 사이에서는 클라벨에게 금잠재 4개를 받는 시점을 1회 완주로 보고, 5회 완주 후에 최대 확률에 도달한다고 추측합니다. 이는 커뮤니티 추측이며 공식 확인 정보는 아니나 가장 정설로 받아들여지는 정보입니다.
